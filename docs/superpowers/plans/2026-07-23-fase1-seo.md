# Fase 1 — SEO critici — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: usare superpowers:executing-plans (o subagent-driven-development) per eseguire task-by-task. Gli step usano checkbox (`- [ ]`).

**Goal:** Rendere indicizzabili e non-duplicate le pagine chiave del sito IKTA: ripristinare `/discipline` come pagina reale, aggiungere `canonical` ovunque, completare la sitemap, migliorare i metadata poveri.

**Architecture:** Refactor in-place sul repo Next.js esistente (App Router). Nessun cambio di stack. Si sfrutta il pattern metadata già presente (pagine server esportano `metadata`; pagine `'use client'` usano `layout.tsx` wrapper).

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind 4, deploy Vercel.

## Global Constraints

- Next.js 16 App Router; TypeScript; nessuna nuova dipendenza in questa fase.
- `metadataBase` è già `https://iktaworld.com` (in `src/app/layout.tsx`) → i `canonical` si scrivono come path relativi (es. `/gare`).
- Lingua `it`. Mantenere gli URL esistenti; 301 solo dove una route cambia.
- **Nessun test framework nel progetto** → la verifica di ogni task è `npm run build` + `npm run lint` + controllo manuale sul dev server (`curl` + `grep`). Non inventare test unitari.
- Brand/colori invariati (già conformi a `BRAND.md`).
- Commit frequenti, uno per task.
